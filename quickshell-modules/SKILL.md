## When to Use
Use when building, fixing, or debugging any quickshell module, panel, or popup in ~/dotfiles/.config/quickshell — especially when the bar disappears, IPC targets go missing, a new window misbehaves, or redesigning UI (ControlCenter, DriveHealth, panels). ALL new/styled UI must follow the Amber Bento design language (see the Amber Bento step in Procedure) — keep it consistent, do not invent new colors or spacing.

## Procedure
1. Read ~/dotfiles/.config/quickshell/AGENTS.md first — canonical path is always quickshell -p ~/.config/quickshell, identical string everywhere.
2. Pick the module kind: PILL = Item bar widget (property var colors, signal openRequested(), readonly derived props, no window — e.g. Battery.qml). PANEL = PanelWindow dropdown (anchors all four sides, ExclusionMode.Ignore, transparent, visible: root.open so closed means fully gone, Esc + click-outside backdrop in the SAME window — sibling PanelWindows stack unpredictably. Gives it a qs-* WlrLayershell.namespace matched by blur layerrules). CARD = FloatingWindow centered popup (title, implicitWidth/Height plus minimumSize/maximumSize, visible: root.open, Hypr float+center+size windowrules for both class quickshell and org.quickshell, and NEVER any WlrLayershell.* prop).
3. Ownership: quick bar toggles live in Bar.qml as Named { id: x; colors: palette } so pills wire by id (onOpenRequested: wifiPanel.open = !wifiPanel.open). Standalone popups live in shell.qml top level as Name { colors: barPalette }. Every visual module takes property var colors (only LockScreen/NetRate are exempt).
4. IpcHandler is always target: "<name>" with function toggle(): void { root.open = !root.open } (calendar pinning via bar is the lone exception). Add the Hypr bind as quickshell -p ~/.config/quickshell ipc call <target> toggle. Esc must close the surface.
5. Develop new modules in a scratch instance (/tmp/pltest + QtObject color stub) so the live bar never breaks; bisect poison with an outsider-canary IpcHandler — if outsider is missing from ipc show, halve the module until it registers.
6. Parse-check edits before restarting: timeout 6 quickshell -p ~/.config/quickshell 2>&1 | grep -E 'ERROR|Loaded' (a timeout is fine, it just runs the config for 6s). Only when it prints Configuration Loaded, do the real restart.
7. Restart fresh (pkill -x quickshell; setsid quickshell -p ~/.config/quickshell) for verdicts — never trust hot reload alone. Hypr rule changes need hyprctl reload.
8. STYLE new UI in the AMBER BENTO design language (house style, keep consistent): CARD = 16px radius, colors.alpha(colors.surface,0.4) fill, 1px border colors.alpha(colors.outline,0.14). LABEL = 7px Bold uppercase, letterSpacing 1.3, colors.alpha(colors.outline,0.55) (section) / 0.65 (widget title). CHIP = 22-26px circle, alpha(accent,0.15) fill + alpha(accent,0.3) border, 12px glyph in accent. SLIDER/PROGRESS = 7px track colors.alpha(colors.surfaceVariant,0.55), gradient or 0.9-alpha accent fill, 18px handle with colors.background fill + 2px accent border. NUMBER = 14px ExtraBold for headline values, 10px ExtraBold for stats/%. GLYPH = FiraCode Nerd Font everywhere, icons as glyphs not images. ACCENTS by purpose: primary/amber #f3bc87 = brand+interactive, secondary/tan #dfc1a8 = complementary, tertiary/ice #9bcee3 = data/network. Values on graphs must be readable (PEAK label + per-bar values) — never bare bars.
9. ICONS must verify by GLYPH NAME, never by charset presence. Nerd/MDI codepoints drift between font builds: U+F01C1 was file-pdf-box upstream but is md-currency_usd (a literal $) in this FiraCode build — charset presence checks passed and it still rendered wrong. Verify every codepoint (old and new) with fontTools before shipping:
  python3 -c "from fontTools.ttLib import TTFont; print(TTFont('/usr/share/fonts/TTF/FiraCodeNerdFont-Regular.ttf').getBestCmap()[0xF1C1])"
  The printed name must match intent (fa-file_pdf_o, md-folder, fa-check…). Presence-only checks (fc-query charset, getBestCmap key test) are NOT sufficient.
10. FLOATING WINDOW sizing is content-driven, not rule-driven. Hypr `size` rules apply at map, then QML content implicit size resizes the window inside min/max — every converted window opened at min/max clamps instead of its rule. So: set min/max honestly around the MEASURED open size (hyprctl clients -j), pin scroll views with Layout.preferredHeight, make grid cells fluid (cellWidth: Math.max(150, Math.floor(view.width / Math.max(2, Math.floor(view.width / 178)))), delegates width: GridView.view.cellWidth - 8), and never trust the rule alone. Position quirk: expect odd top-left offsets on quickshell windows even with `center on` — cosmetic, not worth chasing.
11. NO `var` statement blocks inside property bindings — the parser throws `Unexpected token ';'` and the whole shell fails to load (no bar, no IPC). `text: { var f = …; return … }` is fatal; use ternary expressions or named functions/properties instead. `function(e){…}` handlers and onX blocks are fine.
12. FLOATING WINDOW glass recipe (all three required): `color: "transparent"` on the window itself (default paints opaque behind your glass), inner rect colors.alpha(colors.surface, 0.4) (0.9+ kills the blur-behind effect), 16px radius. Converted overlays must also drop the click-blocker backdrop MouseArea and the Wayland import when unused.
13. RENAME SWEEP: when a window title changes, grep windowrules.conf + bindings.conf + KeybindsPanel.qml + looknfeel.conf layerrules together — a stale title (PhoneLink vs PhoneBridge) fails silently, rules just never match. Delete the dead qs-* layerrules and `hyprctl reload`.
14. UNBIND ORDER in bindings.conf: `unbind` kills previously-defined matches, so a stale unbind placed AFTER a new bind silently deletes it (SUPER CTRL SPACE case). Put unbinds directly ABOVE the bind they clear, then confirm with `hyprctl binds | grep -B8 <arg>` that exactly one entry exists.
15. MATUGEN full-regen danger: `matugen image <wall>` without the exact original flags can flip the entire palette (sage→teal incident) AND dirty every generated file. Prefer rendering a single template from live colors.css; after ANY matugen run immediately `git diff --stat` and revert collateral (colors.css, cava, rofi, zed) before doing anything else.
16. PARTIAL COMMITS: the tree is always dirty with other work — stage only your hunks via a hunk-split patch (`git diff -U3 <file> | awk … > /tmp/hunk.patch` with diff header prepended, `git apply --cached`) so nothing pre-existing rides along. Generated-file moves (stowing ~/.config/zathura into dotfiles + relative symlink mirroring the quickshell one) are committable; untracked helper bins are not.
9. Reuse existing helpers before writing new ones (fmtDurShort, fmt, condGlyph, NetRate rx/tx history).
10. Preserve embedded logic byte-identical when redesigning: Process blocks, properties, functions, IpcHandler, timers stay untouched; only the visual layer is edited (user requirement for ControlCenter/DriveHealth).

## Pitfalls
- Charset presence is NOT glyph verification (see step 9) — always confirm the glyph NAME matches intent; MDI drift turned file-pdf-box into a dollar sign.
- ListModel delegates have NO `modelData` (named roles only) — passing it yields undefined (the Wallshelf double-click bug). Plain-JS-array models DO have modelData; prefer `wAt(index)` style accessors.
- Search-while-loading races: `if(loading){ queued=true; return }` swallows a reset — carry a second `resetQueued` flag and drain both at every completion path.
- Never call a function from a handler without grepping its definition first — `clearFinished` shipped called-but-undefined and threw on click.
- Never ship an invented Nerd Font codepoint — a wrong codepoint renders as a tofu box. Verify candidates against the actual font file first: fc-query --format=%{charset} <font.ttf> (parse bare hex tokens and 'a-b' ranges), or copy glyphs verbatim from existing modules (NowPlaying: prev 󰒮, play 󰐊, pause 󰏤, next 󰒭 — note prev/next are the OPPOSITE of the Material Design glyph names). Reuse proven glyphs: 󰂛/󰂚 dnd, 󰃠 sun, 󰇚/󰕒 dl/ul, 󰐥 power, 󰌾 lock, 󰉏 camera, 󰅌 clipboard, 󰳨 vibrate, 󰕽/󰕾/󰝟 volume.
## Verification
1. hyprctl layers shows qs-bar (1584x54) plus your window's namespace when open
2. quickshell ipc --pid <main-pid> show lists every target including the new one
3. Fresh instance log has 0 TypeError lines
4. ipc call <target> toggle opens the window (check floating + size via hyprctl clients -j) and toggles it shut
5. Parse check: timeout 6 quickshell -p ~/.config/quickshell 2>&1 prints 'Configuration Loaded' with no ERROR lines before the restart verdict
6. UI check: open the panel, confirm no overlaps (every mixed-height row label vertically centered), no ellipsis/overflow on elided texts, no layout jumps when long names swap in
7. Amber Bento check: new/styled widgets use only the token values (radii 12/16, label 7px/1.3, chip 22-26, track 7px) and palette accents — no off-palette colors
8. Commit only your files; leave pre-existing dirty files (PLUGINS.md, .local/bin, plan.md) alone unless asked
9. Delivery loop that works: parse-check → fresh restart (never trust hot reload) → 0 TypeError → `quickshell -p ~/.config/quickshell ipc --pid <pid> call <target> toggle` → confirm geometry via `hyprctl clients -j` (at/size/floating) → user verifies visually. Do NOT screenshot for the user unasked — they verify.
