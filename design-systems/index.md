# Design Systems Library — index

Stored visual references in this directory (`design-systems/`). Use them as
**inspiration, not full adoption**: borrow tokens, components, or moods
selectively. The current brief always wins on conflicts — never force a
reference's palette, type, or chrome onto a brief that points elsewhere.

## How to use

1. Read this index, pick at most one or two systems that fit the brief's mood.
2. Read only the chosen file(s) — never load all four.
3. Borrow selectively (e.g. Timescale's stats banner, Perk's lime CTA) and
   re-skin to the brief's own tokens where they conflict.
4. Keep obeying the global forbidden rules in `frontend-design/SKILL.md`
   unless the brief explicitly asks for the banned thing.
