# Design Systems Library

Stored visual references for inspiration, not full adoption. Borrow
tokens, components, or moods selectively — the current brief always
wins on conflicts.

## Procedure

1. Read `index.md` in this directory — the router table (vibe, palette,
   type, when to reach for each).
2. Load at most one or two system files that fit the brief's mood.
   Never load all of them.
3. Re-skin borrowed ideas to the brief's own tokens where they conflict.
4. Keep obeying the global forbidden rules in `frontend-design/SKILL.md`
   unless the brief explicitly asks for the banned thing.
